# 台股趨勢選股器（朱家泓技術分析版）

每個交易日晚上掃描全部上市＋上櫃股票，依朱家泓《活用技術分析寶典》的轉折波、均線、K 線、成交量規則，找出「明天可能出現進場 K」的股票，算好觸發條件用 LINE 推給你；隔天盤中再檢查兩次。全部跑在 GitHub 上，免費、不用開電腦。

| 時間（台灣） | 做什麼 |
|---|---|
| 週一～五 晚上 | 抓當天收盤 → 判斷大盤 → 選出多方／空方預備名單 → LINE 推播 |
| 隔天 10:55 | **預警**：哪些預備股正在走出進場 K（還早，僅供參考） |
| 隔天 13:00 | **確認**：離收盤 30 分鐘，可以準備下單 |

> 進場以「收盤確認」為準：盤中「成形」只代表目前符合，13:30 收盤價才算數。

---

## 判斷流程

**1. 大盤（10-5 進場前提、11-1 資金分配）**
用同一套方法判斷加權指數，推播最上面會顯示大盤狀態和建議資金水位。
大盤在月線上只推多方，月線下只推空方（`config.py` 的 `MARKET_FILTER` 可關掉）。

| 大盤狀態 | 建議資金 |
|---|---|
| 多頭確認 | 3 成 |
| 多頭，站上月線 | 4～5 成 |
| 中長多頭（四線多排） | 6～8 成 |
| 多頭末升段 | 5 成 |
| 盤整，出現頭頭低 | 5 成以內 |
| 空頭確認 | 4 成 |
| 中期空頭（四線空排） | 3 成 |
| 長期空頭 | 2 成 |

**2. 轉折波與趨勢（2-1～2-4）**
- 收盤跌破 5 日線：正價群（含當天）的最高點＝頭；收盤突破 5 日線：負價群（含當天）的最低點＝底
- 從最後一根 K 線往左，和最近的頭、底比較：頭頭高＋底底高＝多頭，頭頭低＋底底低＝空頭，其他＝盤整
- 位階用月線（20 日）長期轉折波：初升段優先、主升段排後面、末升段不做

**3. 進場位置（11-1 八種進場位置、12-1 高勝率進場位置）**

| 多方 | 空方 |
|---|---|
| 打底完成突破 | 盤頭確認 |
| 回後買上漲（不破前低、不破月線） | 彈後空下跌（不過前高、不過月線） |
| 突破盤整上頸線 | 跌破盤整下頸線 |
| 橫盤／一字底突破 | 跌破橫盤／一字底 |
| 突破大量黑K（3 日內） | 反彈後跌破紅K低點 |
| ABC 修正突破切線（切線畫在轉折波的頭） | 假突破真下跌 |
| 假跌破真上漲 | |

**4. 明天的觸發條件（短線波段操作守則第 1 條）**
收盤要同時：站上 5 日線、突破今天高點、漲 2% 以上（做空反過來），而且要是實體紅K（價漲的黑K不算）、上影線不超過一半、K 值向上、量達到要求（大量＝5 日均量 1.2 倍）。

**5. 排除**：做多／做空各 10 大戒律、短線守則第 12、14 條、末升段、相對強度（做多要強勢股、做空要弱勢股）。被排除的股票和原因會列在網頁「被戒律排除」分頁。

**6. 停損**：固定停損＝進場價 5%；另附趨勢停損（回後買上漲用轉折波低點、突破型用突破點）和 K 線停損（進場 K 最低點）當參考。

所有數字都在 `config.py`，書上沒寫明確數字、由我們自訂的會標「自訂」，想調整直接改那個檔案。

## 從舊版升級

1. 把這次的檔案全部上傳到 GitHub 覆蓋（`.github` 資料夾不用動）
2. 到「Actions」→「晚上選股掃描」→「Run workflow」手動跑一次。**這次要多補半年的歷史資料（週線判斷需要），大約 30～60 分鐘**，之後每天一樣只要幾分鐘
3. 盤中檢查由 cron-job.org 準時觸發兩個任務：**10:55 預警**、**13:00 確認**
4. GitHub 原本的盤中排程留著當備援，同一時段只會推一次，不會重複通知。`.github/workflows/check.yml` 的排程和排隊設定請改成：

   ```yaml
   on:
     schedule:
       - cron: "55 2 * * 1-5"   # 10:55 預警的備援
       - cron: "5 5 * * 1-5"    # 13:05 確認的備援（一定要在 13:00 之後）
     workflow_dispatch:

   concurrency:
     group: check
   ```

   12:00～12:59 執行的（測試或手動補跑）算「盤中」，會推播但不影響 13:00 的確認。

## 第一次設定（約 30 分鐘）

### 步驟 1：拿到 LINE 的兩個金鑰

1. 到 [LINE Official Account Manager](https://manager.line.biz/) 登入，選你的官方帳號
2. 右上角「設定」→ 左邊「Messaging API」→ 按「啟用 Messaging API」，選一個提供者（Provider，沒有就新建一個，名字隨便取）
3. 到 [LINE Developers](https://developers.line.biz/console/) 登入，點剛剛的提供者 → 點你的官方帳號那個 channel
4. 在 **Basic settings** 分頁拉到最下面，找到 **Your user ID**（U 開頭的一長串）→ 複製下來，這是 `LINE_USER_ID`
5. 在 **Messaging API** 分頁拉到最下面，**Channel access token (long-lived)** 按「Issue」→ 複製下來，這是 `LINE_CHANNEL_ACCESS_TOKEN`
6. 同一頁有 QR code，**用手機掃描把你的官方帳號加為好友**（沒加好友收不到推播）

> 這兩個值等於官方帳號的鑰匙，不要貼在任何公開的地方。

### 步驟 2：開 GitHub 帳號、建立專案

1. 到 [github.com](https://github.com) 註冊帳號（免費）
2. 右上角「＋」→「New repository」
   - Repository name：`tw-screener`
   - 選 **Public**（免費帳號要 Public 才能開網頁；金鑰另外存放，不會公開）
   - 按「Create repository」
3. 在新頁面點「uploading an existing file」
4. 把解壓縮後 `tw-screener` 資料夾**裡面的所有檔案和資料夾**一起拖進去（包含 `.github` 資料夾，這個很重要，排程設定在裡面）
5. 拉到下方按「Commit changes」

> 上傳完確認一下，頁面上應該看得到 `.github`、`docs`、`tests` 三個資料夾和 `scan.py` 等檔案。如果沒有 `.github`，就另外點「Add file → Upload files」單獨把它拖進去。

### 步驟 3：把 LINE 金鑰存到 GitHub

1. 在專案頁面點上方「Settings」
2. 左邊「Secrets and variables」→「Actions」→ 綠色按鈕「New repository secret」
3. Name 填 `LINE_CHANNEL_ACCESS_TOKEN`，Secret 貼上步驟 1 的 token → Add secret
4. 再新增一個：Name 填 `LINE_USER_ID`，Secret 貼上 U 開頭的那串 → Add secret

### 步驟 4：開啟網頁

1. 還是在「Settings」，左邊點「Pages」
2. Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/docs` → Save
3. 等 1～2 分鐘，上方會出現網址，長得像 `https://你的帳號.github.io/tw-screener/`，用手機加到主畫面

### 步驟 5：第一次手動執行

1. 點上方「Actions」分頁（如果有提示要啟用，按綠色按鈕啟用）
2. 左邊點「晚上選股掃描」→ 右邊「Run workflow」→ 再按一次綠色「Run workflow」
3. **第一次要回補一年多的歷史資料，大約 30～60 分鐘**，之後每天只要 2～3 分鐘
4. 跑完（出現綠色勾勾）LINE 就會收到第一份清單，網頁也會有資料

之後就全自動了，不用再做任何事。

## 常見問題

**有紅色叉叉（執行失敗）怎麼辦？**
點進去那次執行 → 點有紅叉的步驟，把錯誤訊息截圖給我，我幫你看。

**想排除某些股票（例如全額交割股、不想碰的股票）？**
在 GitHub 上點 `exclude.txt` → 右上角鉛筆圖示編輯 → 一行寫一個代號 → Commit changes。

**想改參數？**
同樣方式編輯 `config.py`，改完下一次執行就生效。想馬上看結果，到 Actions 手動 Run workflow。

**GitHub 寄信說排程被停用？**
長時間沒有人動專案時 GitHub 可能會暫停排程，到 Actions 頁面按「Enable workflow」就恢復。

## 已知限制

- 使用的是**未還原權息**的價格，除權息當天的跳空會讓轉折波、均線判斷失準，那幾天的訊號要自己多看一眼
- 盤中量能是用「目前成交量 ÷ 已開盤時間 × 全天」推估的，早盤量通常比較大，10:55 的推估會偏樂觀
- 證交所、櫃買中心的網站格式偶爾會改，如果某天突然抓不到資料，把錯誤訊息給我就能修
- 規則是把書上的文字轉成程式條件，有些地方（例如「乖離過大」）書上沒寫數字，是我們自訂的，會持續依實際結果調整
- 這是技術面篩選工具，只負責找出值得看的股票，**不構成投資建議**，下單前請自己判斷

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `config.py` | 所有參數 |
| `data.py` | 抓證交所／櫃買中心每日行情、加權指數 |

| `.github/workflows/` | 自動排程設定 |
